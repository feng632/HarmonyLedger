记账 Ledger 隐私政策

应用名称：记账 Ledger
应用包名：com.feng.myledger
更新日期：2026年8月3日

感谢您使用「记账 Ledger」（以下简称"本应用"）。我们非常重视您的个人信息和隐私保护。本隐私政策旨在向您说明，在使用本应用的过程中，我们如何处理和保护您的信息。

一、信息收集与使用

1. 记账数据

  • 您在本应用中录入的记账数据（包括收支金额、分类、备注、日期等）仅存储在您的手机本地（应用沙箱目录）。
  • 本应用不上传、不收集、不分享您的任何记账数据。
  • 卸载应用或清除数据后，记账数据将一并删除。

2. 语音记账（可选功能）

  • 当您使用语音记账功能时，会调用华为系统语音识别服务将您的语音实时转换为文字，用于自动填入记账表单。
  • 语音内容仅用于本次识别，不会被本应用存储或留存。
  • 语音识别为在线服务，需要网络连接；识别过程由华为语音服务完成。
  • 您可以在系统设置中随时关闭本应用的麦克风权限，关闭后语音记账功能将不可用。

3. 通知权限

  • 当您设置预算并授权后，本应用会在预算超支时发送系统通知提醒您。
  • 通知内容仅包含预算使用情况，不包含其他个人信息。
  • 您可以在系统设置中随时关闭本应用的通知权限。

4. 震动反馈

记账操作时可能触发轻微震动反馈（物理反馈），不涉及信息收集。

二、权限说明

权限用途可关闭
麦克风（MICROPHONE）语音记账时识别语音✅ 可在系统设置关闭
通知（NOTIFICATION）预算超支提醒✅ 可在系统设置关闭
网络（INTERNET）语音在线识别✅ 关闭后语音功能不可用

本应用不申请：通讯录、位置、相册读取（选壁纸使用系统选择器，不直接读取相册）、存储等敏感权限。

三、信息存储

  • 所有记账数据仅存储于您的手机本地，本应用没有服务器，不会将任何数据传输到外部。
  • 应用壁纸（您选择的照片）仅存储于应用沙箱目录，仅用于应用内显示。

四、信息共享

本应用不与任何第三方共享您的个人信息。语音识别过程由华为系统服务完成，识别结果仅用于当次输入，本应用不存储语音内容。

五、儿童隐私

本应用不面向儿童设计，不收集儿童个人信息。详见《未成年人保护声明》。

六、您的权利

  • 您可以随时在应用内导出备份您的记账数据（JSON 文件），或删除任意记录。
  • 您可以随时卸载本应用，卸载后所有本地数据将被删除。
  • 您可以随时在系统设置中关闭本应用的各项权限。

七、政策更新

我们可能会根据功能变化更新本隐私政策。更新后的政策将在本页面展示，并标注更新日期。

八、联系我们

如您对本隐私政策有任何疑问，可通过 GitHub 仓库（https://github.com/feng632/HarmonyLedger）与我们联系。

本应用为个人开发者作品，坚持"数据属于用户"原则：您的记账数据只属于您自己。

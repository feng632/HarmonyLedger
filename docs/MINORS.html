记账 Ledger 未成年人保护声明

应用名称：记账 Ledger
应用包名：com.feng.myledger
更新日期：2026年8月3日

一、总则

「记账 Ledger」（以下简称"本应用"）重视未成年人的个人信息保护。根据《中华人民共和国未成年人保护法》《儿童个人信息网络保护规定》等法律法规的要求，特制定本未成年人保护声明。

二、本应用不面向未成年人设计

本应用为个人记账工具，不面向未成年人设计，不包含任何面向儿童的广告、内容或功能。本应用的使用者应为年满十八周岁的成年人。

三、未成年人使用本应用的建议

若未成年人确需使用本应用，应在监护人知情并同意的前提下使用，且监护人应：

  • 指导未成年人正确使用本应用；
  • 帮助未成年人理解记账数据的含义；
  • 监督未成年人合理使用本应用，避免沉迷。

四、未成年人信息保护

本应用不收集用户的个人信息：

  • 记账数据仅存储在用户手机本地，不上传、不共享；
  • 不要求注册账号，不收集姓名、年龄、联系方式等身份信息；
  • 语音记账仅实时转换文字用于录入，不存储语音内容。

因此，本应用不涉及对未成年人个人信息的收集、使用、共享。

五、监护人权利

如您是未成年人的监护人，且认为本应用存在任何可能影响未成年人权益的情形，您有权：

  • 要求删除相关数据（在应用内删除记录或卸载应用）；
  • 通过本声明下方的联系方式与我们联系，我们将在合理期限内处理。

六、联系我们

如对本未成年人保护声明有任何疑问，可通过 GitHub 仓库（https://github.com/feng632/HarmonyLedger）与我们联系。
